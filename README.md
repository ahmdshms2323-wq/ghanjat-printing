# غنجات للطباعة - Flutter Starter

نسخة أولية لتطبيق موبايل لإدارة طلبات مطبعة غنجات.

## الموجود حالياً
- واجهة رئيسية بألوان غنجات: تركواز + بنفسجي + أبيض
- صورة البانر المرفوعة من المستخدم داخل التطبيق
- ملخص الطلبات والمبيعات
- الخدمات الرئيسية
- أحدث الطلبات
- شاشة الطلبات
- شاشة إضافة طلب جديد
- حساب المتبقي تلقائياً
- شاشة عملاء أولية
- شاشة المزيد
- أرقام التواصل: 0994482612 / 0115494130

## التشغيل
1. ثبّت Flutter.
2. افتح المجلد في VS Code أو Android Studio.
3. من داخل المجلد شغّل:
   flutter pub get
   flutter create .
   flutter run

ملاحظة:
المشروع هنا يحتوي على ملفات التطبيق الأساسية. أمر `flutter create .` ينشئ مجلدات Android/iOS/Web القياسية بدون تغيير lib/main.dart.


## قاعدة البيانات المحلية
تمت إضافة SQLite باستخدام `sqflite`.

الجداول:
- customers: العملاء
- services: الخدمات
- orders: الطلبات
- payments: الدفعات

الطلبات تُحفظ داخل الهاتف ولا تختفي بعد إغلاق التطبيق.

للتشغيل:
1. `flutter pub get`
2. `flutter create .`
3. `flutter run`


## إصلاح مشكلة الحزم
هذه النسخة تستخدم إصدارات أكثر توافقاً مع Flutter/Dart:
- sqflite: ^2.3.3+1
- path: ^1.9.0
- flutter_lints: ^3.0.2
- Dart SDK: >=3.0.0 <4.0.0

إذا ظهرت مشكلة عند فتح المشروع:
1. احذف مجلد `.dart_tool` وملف `pubspec.lock` إن وُجدا.
2. شغّل: `flutter clean`
3. شغّل: `flutter pub get`
4. شغّل: `flutter run`

ولو المشروع لا يحتوي مجلد android:
شغّل مرة واحدة: `flutter create .`
ثم: `flutter pub get`
